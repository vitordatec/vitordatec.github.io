OF Stream Backup

Ferramenta pessoal de backup · Personal backup tool

OF Stream Backup é um aplicativo de uso pessoal que roda no computador do próprio usuário e guarda cópias de segurança de arquivos de mídia na conta do Google Drive desse mesmo usuário. Ele usa apenas a permissão drive.file: só cria e lê os arquivos que ele mesmo enviou, sem acesso ao restante do Drive.

OF Stream Backup is a personal application that runs on the user's own computer and stores backup copies of media files in that same user's Google Drive. It only uses the drive.file scope: it can create and read only the files it uploaded itself, with no access to the rest of the Drive.
