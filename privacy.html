Política de privacidade · Privacy policy

Última atualização · Last updated: 26/10/2026

Português

O OF Stream Backup é um aplicativo pessoal que roda no computador do próprio usuário. Ao conectar uma conta do Google, ele recebe apenas a permissão https://www.googleapis.com/auth/drive.file, que permite criar e ler somente os arquivos que o próprio aplicativo enviou ao Google Drive do usuário.

  • Dados acessados: apenas os arquivos e pastas criados pelo aplicativo no Google Drive do usuário e o e-mail da conta conectada (para identificar a conta).
  • Uso: guardar e reproduzir cópias de segurança de arquivos do próprio usuário.
  • Armazenamento: o token de acesso fica somente no computador do usuário, protegido pelo Windows (DPAPI). Nenhum dado é enviado a servidores do desenvolvedor ou a terceiros.
  • Compartilhamento: nenhum dado é vendido, compartilhado ou usado para publicidade.
  • Remoção: o usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions e apagar os arquivos criados diretamente no Google Drive.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

English

OF Stream Backup is a personal application that runs on the user's own computer. When a Google account is connected, it only receives the https://www.googleapis.com/auth/drive.file scope, which allows it to create and read only the files the application itself uploaded to the user's Google Drive.

  • Data accessed: only the files and folders created by the application in the user's Google Drive, and the connected account's email address (to identify the account).
  • Use: storing and playing back backup copies of the user's own files.
  • Storage: the access token is kept only on the user's computer, protected by Windows (DPAPI). No data is sent to the developer's servers or to third parties.
  • Sharing: no data is sold, shared, or used for advertising.
  • Removal: the user can revoke access at any time at myaccount.google.com/permissions and delete the created files directly in Google Drive.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
